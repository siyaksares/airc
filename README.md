# AIRC

A minimal static landing page and documentation site for AIRC, a developing concept for decentralized AI image generation on Arc.

## Pages

- `index.html` — project landing page
- `docs.html` — vision and conceptual documentation

## Run locally

No build step is required. Open `index.html` directly or start a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` directory.

## Status

AIRC is an early concept. The architecture and features described in the docs may evolve before release.
